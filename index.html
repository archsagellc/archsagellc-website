Hardware

Production Infrastucture

Archsage LLC operates on purpose-built hardware, enterprise networking equipment, and a custom liquid cooling system designed for stability, security, and long-duration rendering workloads.

Enterprise Rendering Platform

Built around the ASUS Pro WS WRX80E-SAGE SE WIFI and AMD Threadripper Pro 5995WX, Archsage's rendering workstation is designed for reliability, sustained performance, and long-duration workloads. The platform includes 256 GB of ECC Registered Memory, an NVIDIA RTX 3080 Ti graphics processor, and dedicated high-speed NVMe storage to support demanding rendering projects.

Custom Liquid Cooling Loop

A fully customized liquid cooling loop provides stable operating temperatures during extended rendering sessions. The system utilizes Optimus CPU and GPU water blocks, an EKWB X560M radiator, Aquacomputer pump/reservoir, sensors, Aquasuite monitoring software, and nine Noctua industrial-grade cooling fans to deliver efficient thermal management under continuous load.

Enterprise Grade Network Infrastructure

Archsage's network is designed to support secure project transfers, remote administration, and dependable connectivity. The environment includes Gigabit Verizon FiOS service, Ubiquiti enterprise networking equipment, and WireGuard remote access tunnel. Utilizing all Ubiquiti equipment allows Archsage to ensure that wireless infrastructure stays separate from workstation operations and monitor network traffic with relative ease thanks to Unifi UI controls.
